Main Menu Bar & Keyboard Shortcuts

The Tessera Engine top menu bar (src/UI/EditorUI.cpp:578) provides access to project management, scene authoring, entity spawning, viewport camera modes, transform gizmos, and specialized feature windows.

1. Menu Bar Breakdown

1.1 File Menu

Menu ItemShortcutAction & Description
Project Launcher / Hub...—Opens the startup Project Hub to switch between recent projects or create a new workspace.
New Project...Ctrl+NOpens the New Project dialog to initialize a new project workspace directory and .scene file.
Open Project...Ctrl+OOpens the Windows file browser to select and load an existing project configuration.
Save ProjectCtrl+SSaves the project, flushing scene files, project configs, and newly imported asset paths to disk.
Save Project As...—Duplicates the entire project directory into a new destination folder.
Recent Projects—Cascading submenu displaying the last 10 opened project paths for instantaneous one-click loading.
Export Game (Windows & Web)...Ctrl+BOpens the Game Exporter modal to package a standalone Windows executable (.exe), Linux Standalone (x86_64 / SteamOS), or Web / HTML5 (WebGL2) game.
Game Localization...Ctrl+LOpens the Game Localization & Translation Editor to manage game translation keys, create new languages, and edit project localization tables.
Project Input & Key Bindings...Ctrl+KOpens the Project Input Settings modal to rebind keyboard, mouse, and gamepad input axes.
Import 3D Model...—Opens a native file picker for external 3D models (.fbx, .gltf, .glb, .obj) and imports them into the scene.

1.2 Edit Menu

Menu ItemShortcutAction & Description
Undo [Action Name]Ctrl+ZReverts the last scene modification recorded by Core::UndoRedoManager (e.g. transforms, additions, deletions).
Redo [Action Name]Ctrl+Y / Ctrl+Shift+ZRe-applies the next action in the undo history stack.
Copy Selected NodeCtrl+CSerializes the selected node and all its children into the internal clipboard buffer.
Paste NodeCtrl+VInstantiates the clipboard node tree into the active scene as a new duplicate.
Duplicate Selected NodeCtrl+DDuplicates the selected node in place with a single keypress.
Delete Selected NodeDelRemoves the selected node and its child hierarchy from the scene graph.

1.3 Scene Menu

  • New Scene...: Prompts for a scene name and initializes a clean, empty level.
  • Open Scene: Dropdown submenu listing all scenes found within the project's scenes/ folder.
  • Save Scene: Writes the active level's node graph to its .tess JSON file.
  • Save Scene As...: Prompts for a new scene filename.
  • Add Node / Entity... (Ctrl+A): Opens the searchable Quick Add palette containing all 30+ nodes.
  • Add Primitive: Submenu for fast spawning of Cube, Sphere, Cone, Cylinder, or Plane.
  • Add Entity: Submenu for Camera, Point Light, Directional Light, Spot Light, Audio Source, Particle Emitter (presets in the Inspector: fire, smoke, fog, sparkles, explosion, sparks, heat haze, ribbon, rain splashes), Terrain, Fluid Volume, Pour Spout, Ocean, Decal Projector, Spline, or Empty Group.
  • Add In-Game Video Screen...: Quick-spawn presets for 3D surfaces and cutaways:
    • Living Room TV Set (16:9): 16:9 widescreen television playing procedural TV News with Doppler radar and stock ticker.
    • Cinema Projection Screen (2.39:1): Ultrawide movie screen playing vintage 35mm countdown and film reel.
    • Smartphone / Mobile Screen (9:16): Vertical mobile phone display with OS status bar and music equalizer.
    • CCTV Security Monitor: 4:3 monochrome night-vision camera feed with timestamp and motion tracking box.
    • Retro CRT Color Bars: 4:3 vintage tube television with SMPTE color test bars and analog VHS tracking noise.
    • Sci-Fi Holographic Radar: 1:1 circular sweep radar display with detected blips and telemetry readouts.
    • 2D UI Video Player Node: Screen-space UI video player widget with interactive click-to-pause.
    • Test Fullscreen Cutaway Video: Triggers a high-priority fullscreen video transmission overlay (Space to skip).
    • Test Picture-in-Picture (PiP) Video: Triggers a corner PiP transmission overlay while maintaining gameplay.
  • Add 2D UI Component: Submenu organizing Containers, Basic Text, Controls, Media, and Vector Shapes.
  • Add Collider: Submenu for Box Collider, Sphere Collider, and Capsule Collider.
  • Reset Scene to Default: Resets the scene to the default starter template (sun light, floor plane, camera).
  • Clear All: Deletes all nodes from the scene.

1.4 Camera Menu

  • Reset View: Snaps the editor camera to origin coordinates (0, 2, 5) looking forward.

1.5 Gizmo Menu

  • Translate (W): Activates the 3-axis position translation gizmo.
  • Rotate (E): Activates the 3-axis rotational ring gizmo.
  • Scale (R): Activates the 3-axis scaling box gizmo.
  • World Coordinates vs Local Coordinates: Toggles coordinate frame orientation.

1.7 Language Menu

  • Editor Language Selector: Switches the entire Tessera editor interface between available engine languages (English, Español, etc.). Missing keys automatically fall back to embedded English tables.

1.8 Help Menu

  • Open HTML Documentation...: Launches your default web browser and opens this offline documentation suite directly from docs/index.html.

1.6 Window Menu

  • Scene Hierarchy Panel: Toggles the left scene graph entity tree.
  • Node Property Inspector: Toggles the right property inspector dock.
  • Project File Viewer: Toggles the dockable workspace disk explorer.
  • Performance & Resource Profiler (Shift+F): Toggles live RAM/VRAM tracking, CPU/GPU stage profilers, and orphan node repair.
  • GPU Profiler (Ctrl+9): measured GPU time of every pass, nested, with a frame-time graph.
  • Enable Temporal Upscaling (FSR 3 / DLSS): Quick toggle in the Render menu to activate temporal resolution scaling, motion vector reconstruction, and RCAS sharpening.
  • Enable Meshlet GPU Virtualization: Quick toggle in the Render menu to activate GPU cluster virtualization, meshlet frustum culling, and normal cone backface culling.
  • Enable Hardware Ray Tracing (Vulkan / Metal): Quick toggle in the Render menu to activate hardware ray-traced ambient occlusion (RTAO), reflections (RTR), shadows (RTS), and global illumination (RTGI).
  • Rendering, GI & Post-Processing (Shift+R): Toggles the rendering panel: tone mapping and anti-aliasing, shadows, sky (time of day, moon, clouds), weather and HDRI, Baked & Dynamic Lighting (GI & Real-Time Voxel GI / VXGI), Performance (occlusion culling), colour grading and LUTs, GTAO, SSR, volumetric fog, and camera effects. Also accessible via the top-level Render menu for quick one-click VXGI toggles.
  • Visual Shader Graph Editor (Shift+G): Toggles the node-based Shader Graph canvas (Save, Save As..., Load..., Apply to Selected Object).
  • Audio Mixer & Reverb Zones (Shift+A): Toggles the 4-channel audio mixer and DSP panel.
  • Navigation & NavMesh Baker (Shift+N): Toggles the NavMesh generator and path visualizer.
  • Game Localization Editor (Ctrl+L): Toggles the game localization manager to create and edit project translations, new languages, and key-value tables.
  • Multiplayer & Networking (Shift+P): Toggles the Client-Server connection and authority panel.
  • Animation State Machine Graph (Shift+M): Toggles the visual animation graph canvas.
  • Cutscene & Cinematic Sequencer (Shift+C): Toggles the in-engine cutscene sequencer (location triggers, multi-shot camera choreography, character walk-to-mark & animation transitions, Sepia/B&W/Noir/Vignette/DoF camera effects, audio/silent subtitles, and skippable playback).
  • 3D Ruler & Measurement Tool (M): Toggles the 3D tape measure and precision dimension tool in the viewport and opens the measurement window.
