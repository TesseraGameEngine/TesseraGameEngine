Editor Windows, Inspector & Modals

The Tessera Editor interface is arranged into dockable, highly configurable panels (src/UI/EditorUI.cpp) providing visual scene construction, component editing, real-time audio and rendering adjustments, animation state authoring, and standalone bundling.

1. Scene Hierarchy Panel (Left)

Displays the active scene graph in a hierarchical tree view:

  • Parenting & Reordering: Drag and drop nodes onto other nodes to parent them. Use the up (▴) and down (▾) buttons to reorder sibling nodes.
  • Visual Node Badges: Identifies node categories at a glance (e.g. [3D], [UI], [CAM], [LGT], [Rigged FBX], [COL], [Prefab]).
  • Search Filter: Instant search bar at the top filtering nodes by name.
  • Context Menu: Right-click any node to access Add Child Node, Rename, Duplicate, Copy, or Delete.

2. Node Inspector Panel (Right)

Displays all components, parameters, and options of the currently selected node:

2.1 Header & 3D Model Asset Picker

  • Bidirectional Deletion: Prominent red Delete Node from Scene [Del] button at the bottom of the inspector (works for all entities, including Camera nodes).
  • Node ID & Hierarchy Badges: Displays numerical ID, root/child status, and [Prefab] indicator when instanced from an external .tess scene.
  • Prefab Provenance & Reload Button: If the node is a scene instance root, displays the source file path and a [ Reload Prefab From Disk ] button to re-sync any disk changes immediately.
  • Name Input Field: Edit the node's identifier string.
  • Shape Type Dropdown: Switch between Cube, Sphere, Cylinder, Cone, Plane, or Custom 3D Model Asset.
  • 3D Model Asset Slot:
    • Text Path: Shows relative asset filename (e.g. knight.fbx).
    • [ Browse... ]: Opens Windows Explorer to pick external .fbx, .gltf, .glb, or .obj files.
    • [ X ]: Clears the custom mesh and resets the node to a primitive cube placeholder.
    • Project Models Dropdown: One-click selection of any 3D model found in the project's assets/models/ directory.
    • Geometry Stats: Shows live vertex count, triangle count, and rigged armature indicators.

2.2 Transform Component

  • Local Position: Drag float inputs for X, Y, Z translation.
  • Local Rotation (Degrees): Euler rotation sliders (-180° to +180°) for Pitch, Yaw, Roll.
  • Local Scale: Proportional scaling factors for X, Y, Z.
  • World Position: Readout of the absolute accumulated world-space coordinates.
  • Reset Transform: Resets position to (0,0,0), rotation to (0,0,0), and scale to (1,1,1).

2.3 Material & Appearance (PBR) Component

A live preview at the top shows the material on a sphere, cube or plane (Preview) in a lit studio. In the file browser, hovering a texture or a .shadergraph file shows it on a sphere.

  • Base Color / Tint: Color picker swatch and RGB sliders.
  • Roughness & Metallic: Precision sliders controlling surface specular scatter.
  • PBR Texture Map Slots: Dedicated browse/clear slots for Albedo, Normal, Metallic, Roughness, AO, Emissive, and Height maps (full GPU Parallax Occlusion Mapping with horizon self-shadowing). Multi-material .gltf/.glb and .fbx imports preserve separate materials per primitive/submesh.
  • Emissive Intensity (HDR): HDR multiplier slider for self-illuminating neon and magical surfaces.
  • Alpha Cutoff, Double-Sided, Refraction (IOR): cutout foliage and hair cards, back faces, and glass bending.
  • Material Model: Standard, Skin (Scatter Colour, Scatter Strength, Translucency), Hair (Highlight Tint, Highlight Shift) or Eye (Cornea IOR, Iris Radius (UV), Iris Depth (UV)).
  • Clear Coat / Clear Coat Roughness, Triplanar Mapping, detail albedo / normal maps (Detail Tiling, Detail Strength) and Use Vertex Colours.
  • Mirror, Reflection Probe (with Probe Radius and Box Projection) and GI Volume (Baked Lighting) (with GI Volume Size).
  • Lightmap Static: on for objects that never move, so Bake Lighting gives them a lightmap.
  • Ocean (Ocean nodes only, replacing the material settings): size, waves, water colours, clarity, roughness and foam.
  • Shader Graph Material: shows the applied graph; Open Visual Shader Graph Editor >> opens it.
  • In-Game Video Screen & Display: Enable video playback on this mesh surface:
    • Enable Video Screen: Checkbox activating VideoSystem playback and dynamic Vulkan texture slot @video_<id>.
    • Channel Preset: Dropdown selecting Custom, Cinema Reel (2.39:1), TV News (16:9), CCTV Surveillance (4:3), Smartphone (9:16), Retro CRT Color Bars (4:3), or Sci-Fi Radar (1:1).
    • Video Source File: Path to animated .gif, sprite-sheet atlas (.png/.jpg with custom columns/rows), or folder of sequential frames.
    • Playback Controls: Play, Pause, Rewind buttons, Loop toggle, and Speed multiplier slider (0.1x – 5.0x).
    • Screen Brightness & Emissive Bounce: Slider scaling HDR emission intensity (0.0 – 10.0) that dynamically bounces light into the room via Real-Time VXGI and SSR.
    • Scanline Strength: Horizontal raster phosphor line filter strength (0.0 = clean modern digital, 1.0 = heavy retro CRT).
    • Audio Track & Spatial Sound: WAV audio path, master volume slider, and 3D spatial attenuation toggle.

Details of each option: Rendering, PBR & LOD.

2.4 Level of Detail (LOD) & Mesh Decimation Component

  • Enable Distance-Based LOD: Checkbox activating runtime LOD distance switching.
  • Max Draw Distance: Culling distance threshold in meters.
  • Live Camera Distance Indicator: Displays exact meter distance from camera and shows current active tier (e.g. Active: [LOD0 (Base)]).
  • LOD Preview Override: Force preview any LOD tier directly in the editor viewport.
  • Auto-Generate 3-Tier LODs (50% / 25% / 10%): Triggers QEM decimation to compute LOD1, LOD2, and LOD3 meshes automatically.

2.5 Physics & Dynamics (JoltPhysics) Component

  • RigidBody Mode: None, Static, Kinematic, Dynamic.
  • Mass (kg), Friction, Bounciness: Physical simulation parameters.
  • Use Gravity: Toggles downward gravitational acceleration.
  • Floats on Water and Buoyancy (Dynamic only): bob on an ocean's waves.
  • Joint / Constraint: Fixed, Hinge, Slider, Distance Spring, Cone-Twist.
  • Humanoid Ragdoll Physics: Toggles physical ragdoll bones with impulse testing.
  • 32-Bit Collision Layers & Masks: Interactive bitfield matrix (Layers 1-32, Masks 1-32) configuring Jolt narrowphase filtering.

2.6 Character NPC & Dialogue Settings

  • Character Name & Dialogue Prompt: Conversation text displayed on proximity.
  • Patrol Move Speed & Turn Speed: Navigation parameters.
  • Waypoints List: Add, edit, or delete 3D patrol coordinates.
  • Ground Raycast Clamping: Terrain snapping toggle and ground height offset.
  • Animation Clip Dropdowns: Select active idle and walk animation clips.

2.7 Particle System & Niagara Modules Component

Available when a ParticleNode is selected. Configures real-time visual effect generation, blending, and force integration:

  • 1-Click VFX Presets: Instant one-click configuration dropdown for Fire / Torch Flame, Campfire Smoke, Ground Fog / Mist, Magic Sparkles, and Explosion Burst.
  • Render Mode Dropdown:
    • Billboard (Additive Glow): Camera-facing quads with additive blending and depth-write disabled for fire, magic, and glowing embers.
    • Billboard (Alpha Blend): Camera-facing quads with soft-particle alpha blending and depth-write disabled for smoke and fog.
    • 3D Mesh (Sphere / Cube): Renders 3D solid geometry for physical debris and voxel bursts.
  • Simulation Backend: Toggle between standard CPU emitter and Niagara GPU Compute stack.
  • Emitter Geometry: Switch between Point, Sphere (radius slider), Box (3D extents), and Cone (cone angle slider).
  • Spawn Rate & Capacity: Max Particles (up to 100,000), Spawn Rate (/s), and Min/Max Lifetime ranges.
  • Velocity & Size Curve: Start Speed, Start Size, End Size, and Gravity Multiplier (negative values float upward like hot air).
  • Color Gradients: Start Color (RGBA) and End Color (RGBA) with alpha fade over particle lifespan.
  • Niagara Force Modules:
    • Vortex Force Module: Swirling tangential velocity around an arbitrary 3D axis.
    • Point Attractor Module: Gravitational pull toward a customizable 3D target point.
    • 3D Curl Noise Turbulence: Organic chaotic drift with frequency and strength sliders.
  • Live Burst Testing: Emit Burst (50) and Reset buttons for instantaneous preview in the viewport.

2.8 Terrain Landscape Generator & Sculptor Component

Available when a TerrainNode is selected. Controls grid dimensions, procedural terrain generation, heightmap loading, and interactive sculpting brushes:

  • 1-Click Procedural Landscapes:
    • Rolling Hills: Instantly creates natural undulating hills and gentle slopes.
    • Mountain Peaks: Generates sharp alpine mountain chains, jagged peaks, and ridgelines.
    • Canyons & Ravines: Generates high flat plateaus sliced through by deep river canyons.
    • Flatten: Resets the entire heightfield to a flat zero-elevation plain.
  • Terrain Dimensions & Resolution:
    • Grid Resolution: Dropdown supporting 32×32, 64×64, 128×128, and 256×256 grids. Automatically resamples existing elevation data smoothly when switching resolutions.
    • Size (X, Z): World dimensions in meters (e.g. 100m × 100m, 500m × 500m).
    • Max Elevation (Height Scale): Peak vertical height scale in meters.
    • UV Tiling: Repetition frequency of ground textures across the landscape.
  • Heightmap Image Import: Path input and [ Load ] button to load external grayscale heightmap images.
  • Interactive Viewport Sculpting:
    • Enable Sculpt Mode: Toggles in-viewport cursor sculpting.
    • Brush Actions: Raise (Hills), Lower (Ravines), Smooth, and Flatten (Plateaus).
    • Brush Radius & Strength: Controls falloff footprint and sculpting speed.
    • Viewport Visuals: Displays a bright green 3D circle gizmo tracking the brush position and radius over the landscape.

2.9 Declarative Multiplayer Property Sync Component

  • Enable Replication Checkbox: Toggles automated network state synchronization for this entity.
  • Add Property Rule Dropdown: Select property (e.g. position, rotation, scale, color, animState).
  • Replication Mode Toggle: Choose between On Change (bandwidth-efficient delta packets) or Continuous.
  • Frequency Slider: Set maximum transmission rate (e.g. 20 Hz, 30 Hz, 60 Hz).

3. 3D Viewport Window (Center)

  • Toolbar Controls: Play (F5), Pause, Stop (Esc), Step Simulation (F6).
  • Camera Controls & Desktop Navigation:
    • Right-Click Drag: Orbit camera around focus point.
    • Middle-Click Drag: Pan camera horizontally and vertically.
    • Mouse Wheel: Zoom in and out.
    • Fly Camera: Hold Right-Click and use W, A, S, D, Q, E.
    • Focus (F): Instantly centers and frames the camera on the selected node.
  • Touchscreen & On-Screen Viewport Navigation:
    • Zoom + & Zoom - Buttons: Dedicated blue buttons with continuous touch-and-hold repeat for smooth zooming without requiring a mouse scroll wheel or pinch gestures.
    • Focus [F] Button: Instantly re-centers the camera on the currently selected scene node.
    • Pan Nudge Buttons (<, >, ^, v): Hold-to-repeat buttons to pan the camera left, right, up, and down.
    • Touch Drag Mode Switcher:
      • [Select] (Green): Standard touch mode for selecting objects in the hierarchy and using 3D transform gizmos.
      • [Orbit] (Orange): Enables single-finger touch dragging across the 3D viewport to orbit/rotate the camera view around the scene.
      • [Pan] (Purple): Enables single-finger touch dragging across the 3D viewport to pan the camera view horizontally and vertically.
  • Transform Gizmos (ImGuizmo): Translate (W), Rotate (E), Scale (R).
  • View Display Toggles: Grid toggle, Pivot marker, Polygon mode (Solid vs Wireframe), Preset orthographic views (Front, Top, Side, Iso).
  • Real-size rendering: the viewport renders at its on-screen pixel size. After you resize or redock it, the image follows once the size has been steady for a few frames.
  • Grid overlay: the grid and axes are drawn after post-processing, so they stay sharp under TAA and never receive shadows.

3.1 Camera Preview (Viewfinder Window)

Provides a live preview render of what an in-game camera sees, including UI elements and post-processing. Like the main viewport (and the Game window), it renders at its real on-screen size.

  • Active Camera Selector: Dropdown menu to switch between any CameraNode in your scene.
  • Sync Editor Cam to Scene Cam: Snaps the editor viewport camera to the exact position and orientation of the active scene camera.
  • Touch-Friendly Viewfinder Zoom & Dolly Buttons:
    • Zoom + & Zoom -: Press or hold to narrow or widen the active camera's Field of View (cameraFov), zooming in closer to distant subjects or pulling back for wide-angle framing.
    • Dolly + & Dolly -: Press or hold to physically translate the camera along its local viewing vector, moving forward into the scene or backward away from it.

4. Custom Themed Title Bar & Window Controls

The standard Windows OS white title bar, borders, and controls have been replaced with a seamless, custom borderless title bar (32px height) fully integrated into the engine's cyberpunk dark slate theme:

  • Consistent Across All Startup Stages: The custom title bar is present during the animated Splash Screen, the Project Launcher Hub, and the Main Editor.
  • Brand Icon & Inlined Menus: Features the glowing cyan ⚛ TESSERA logo on the left, immediately adjacent to the main menus (File, Edit, Scene, Camera, Gizmo, Window, Help).
  • Draggable Title & Status Area: Shows the active Project and Scene name in the center. Clicking and dragging anywhere in this region moves the window smoothly; double-clicking toggles between Maximized and Restored states. On Windows, full Aero Snap (snap to edges, corners, and monitor tops) is natively supported.
  • Cyberpunk Window Control Buttons (Top-Right):
    • Minimize (—): Smoothly iconifies the window to the taskbar with soft slate hover highlighting.
    • Maximize / Restore (□ / ⧉): Dynamically toggles between standard windowed view and maximized view fitting the monitor's work area without covering the Windows taskbar.
    • Close (✕): Triggers engine save and exit with vivid crimson red hover highlighting.
  • Borderless Edge Resizing: Hovering within 6 pixels of any border edge or corner displays the appropriate sizing cursor and allows smooth window resizing.

5. Modals Reference

4.1 Input Settings Modal (Ctrl+K)

Configures global input actions (e.g. "Jump", "Fire", "Interact") and directional axes (e.g. "MoveForward", "MoveRight") with primary and secondary keyboard/mouse/gamepad bindings and joystick deadzones.

4.3 Startup Splash Screen & Project Launcher Hub

When starting the engine, an animated high-tech Splash Screen appears during subsystem initialization, followed by the Project Launcher Hub:

  • Animated Splash Screen: Displays the Tessera glowing nucleus logo, version details, and a real-time progress bar tracking Vulkan, Shaders, Lua, and Physics mounting. Can be skipped instantly by clicking or pressing Space / Enter / Esc.
  • Project Launcher Hub (Startup Window):
    • Recent Projects (Left Panel): Displays a scrollable list of recent projects with 1-click [Open] buttons and project status, plus a [Browse for Project File (*.tess)...] button.
    • Create New Project (Right Panel): Configure project name, target directory location, and choose a starting template (3D Standard, Blank Scene, or Third-Person Character Sandbox) followed by [+ Create & Launch Project].
    • Switching Projects: You can return to the Project Launcher Hub at any time from within the editor via File -> Project Launcher / Hub....

4.2 Standalone Game Exporter Modal (Ctrl+B)

Packages your project into a deployable standalone release for Windows or Web:

  • Target Platform Selector:
    • Windows Standalone (.exe):
      • Single-File Bundle (Embedded): Packages all assets, models, textures, shaders, scenes, configs, and DLLs inside a single self-extracting .exe. Zero installation, zero loose files, runs anywhere on Windows.
      • Folder Distribution: Outputs an executable with loose assets/, scenes/, and shaders/ folders.
      • Window & Resolution Modes: 720p, 900p, 1080p, 1440p, or Fullscreen.
    • Web / HTML5 (WebGL 2.0):
      • Zero-Dependency WebGL 2.0 Runtime (`tessera_web.js`): Standalone 3D engine with PBR shaders, procedural geometry, scene parser, and camera transformations.
      • Embed Scene in HTML: Embeds the scene JSON directly into an inline <script> tag in index.html to bypass browser CORS file restrictions when opened via file://.
      • 1-Click Local Web Server Launcher: Exports serve.py (CORS-enabled Python HTTP server on port 8080) and start_server.bat for instant local testing.
      • Mobile Virtual Touch Controls: Adds an on-screen virtual movement joystick and jump button for mobile and tablet browsers.
      • Canvas Display Mode: Choose between Responsive Aspect Ratio (letterboxed auto-scale), Fixed 1280x720 HD, or Fill Entire Browser Window (100vw x 100vh).
      • 1-Click Test Launcher: Click [🌐 Launch in Browser (Start Web Server)] in the export success banner to immediately launch the local server and open your default browser.
    • Linux Standalone (x86_64 / SteamOS):
      • Turnkey POSIX Launcher (launch.sh): Automated bash launcher with isolated LD_LIBRARY_PATH, Vulkan 1.2 runtime configuration, and SteamOS / MangoHud performance monitoring support.
      • Native Linux ELF & Proton/Wine Dual Runner: Directly launches .x86_64 native Linux binary if present, with seamless fallback to Valve Proton or Wine for Windows player builds with Vulkan 1.2 pass-through.
      • Steam Deck & Desktop Launcher (.desktop): Generates an XDG-compliant .desktop entry and Steam-compatible application profile for 1-click "Add a Non-Steam Game" on Valve Steam Deck.
      • Cross-Distro Compatibility: Verified on Ubuntu 20.04+, Debian 11+, Fedora 36+, Arch Linux, and Valve SteamOS 3.
  • Startup Scene: Designate which scene loads upon launching the standalone executable or web page.

6. Live Telemetry & Resource Monitor Window

Available under Window -> Performance & Resource Profiler. Operates in real-time strictly during Play Mode to isolate game metrics from editor UI overhead:

  • Memory Tracking: Live monitoring of RAM Working Set, Committed Heap, Peak Usage, Estimated GPU VRAM Allocation, and Scene Heap.
  • CPU Stage Profiler: Real-time per-frame millisecond budget breakdown across Lua scripts, Jolt physics, skeletal animations, Niagara VFX, and rendering passes with Exponential Moving Average (EMA) smoothing to eliminate text jitter.
  • GPU Pass Profiler: the game view's passes as the GPU timed them (timestamp queries): shadows, prepass, opaque, transparents and VFX, post-processing.
  • GPU Profiler window (Window -> GPU Profiler, Ctrl+9): every pass of every view, nested, with smoothed times, each pass's share of the GPU frame and a frame-time graph, in the editor as well as in Play.
  • Scene Hierarchy Audit & 1-Click Orphan Repair Tool: Real-time audit of active nodes by type (Meshes, Lights, Cameras, Colliders, UI) and automatic detection of orphaned nodes (nodes with missing parents) with a 1-click reparenting repair button that safely re-attaches them to Root.

7. Project Files Viewer Window

Available under Window -> File Viewer:

  • Dockable Workspace Tree Browser: Browse all project directories, scripts (.lua), scenes (.tess), 3D models (.obj, .fbx, .gltf), and configs.
  • Context Menu & Quick Actions: Double-click or right-click files to open scripts in the code editor, load scenes, or drag-and-drop assets directly into the 3D viewport.
  • Unified Docking Ecosystem: Can be docked alongside the Scene Hierarchy or Inspector, or snapped to the bottom tab bar next to the Timeline.

8. Game Runtime Controls & Clean Slate Input Architecture

When a brand new game starts in Editor Play Mode (F5), Windows Standalone (.exe), or Web / HTML5 (WebGL2), Tessera enforces a Clean Slate Architecture with zero default controls:

  • No Unsolicited Movement: The active camera and scene entities remain completely stationary upon starting Play Mode, preventing unwanted camera drift or character hijacking.
  • Developer-Driven Input: All locomotion, camera controls, combat actions, and menus are defined explicitly by the developer via Lua scripting (e.g. Input.is_action_down(...) or Input.is_key_down(...)) or the Project Input Map.
  • Optional Spectator Fly-Cam: If you ever require a quick debug spectator camera while testing large scenes, you can opt in programmatically via gameLoop.SetDefaultCameraControllerEnabled(true).

9. 3D Precision Ruler & Measurement Tool (M)

Available under Window -> 3D Ruler & Measurement Tool [M], through the viewport toolbar button [Ruler: ON/OFF [M]], or via the M shortcut key:

  • Interactive 3D Viewport Measuring: Left-click anywhere in the 3D viewport to place Point A, then click again to anchor Point B. Drag the circular handle rings at either point to dynamically reposition endpoints in real-time.
  • Hero Distance Card & Component Breakdown:
    • Total 3D Euclidean Distance: Large readout formatted in your chosen unit.
    • Component Deltas: Independent orthogonal dimensions: Width (ΔX in red), Height (ΔY in green), and Depth (ΔZ in blue).
    • Ground Distance (XZ): Horizontal planar separation between points ($D_{horiz} = \sqrt{\Delta X^2 + \Delta Z^2}$).
    • Angles: Pitch/elevation angle from horizontal and 8-wind compass heading azimuth (e.g. 45.0° (NE)).
  • 3D Visual Overlays:
    • Delta Triad Guide Box: Renders orthogonal bounding dimension legs connecting Point A to Point B with numerical distance badges.
    • Physical Tick Marks: Subdivides the 3D line into physical 1-meter major tick marks with distance text and 0.25-meter minor ticks.
    • Midpoint Badge: Floating high-contrast label displaying the live distance at the center of the line.
    • Live Rubberband Preview: Tracks mouse position after Point A is placed, showing the distance before clicking Point B.
  • Precision Snapping Modes:
    • Surface / Object Snapping: Real-time raycasting against 3D mesh colliders and bounding boxes. Snaps directly to node centers when within 0.65m.
    • Ground Fallback: Automatically snaps to the infinite ground plane ($Y = 0$) when clicking empty space.
    • Grid Snapping: Quantizes coordinates to configurable increments (e.g. 0.1m, 0.25m, 0.5m, 1.0m, 2.0m).
  • Multi-Unit Support: Instant unit conversion between Meters (m), Centimeters (cm), Millimeters (mm), Feet (ft), and Inches (in).
  • Node-to-Node Quick Measure: 1-click buttons to assign Point A or Point B to the currently selected scene node or measure distance to the world origin (0,0,0).
  • Saved Measurements List: Pin multiple measurements with custom names, toggle individual line visibility, or clear old measurements.

10. Cutscene & Cinematic Sequencer Window (Shift+C)

Available under Window -> Cutscene & Cinematic Sequencer [Shift+C], Scene -> Cutscene & Cinematic Sequencer..., or the Cutscenes... button in the Camera Preview toolbar:

  • 1-Click Demo Cutscene Generator: Click + Create Demo Cinematic Cutscene to automatically build a multi-shot skippable sequence using your scene's characters and camera.
  • Location / Proximity Triggers: Enable Trigger Automatically When Character Reaches Location to start the cutscene as soon as a character or player enters the trigger radius around a target 3D coordinate.
  • Skippable Playback & Audio / Silent Mode: Toggle Skippable (Space / Enter / Backspace or clicking the on-screen Skip Cutscene >> button fast-forwards characters to their end marks and restores the gameplay camera and environment) and Silent Mode (mutes audio cues for silent film or subtitle-only cutscenes).
  • Camera Effects & Color Grading Presets: Apply per-cutscene widescreen 2.39:1 letterbox bars, Sepia Tone, Black & White (Monochrome), Film Noir (High-Contrast B&W), Vintage 35mm Warm, Cold Moonlight, Dreamy Flashback Bloom, Vignette, Film Grain, Chromatic Aberration, and Auto-Focus Depth of Field (DOF).
  • Multi-Shot Camera Cuts, Character Walk Actions & Subtitles: Sequence multiple camera dolly/zoom shots (with live node tracking), character walk-to-mark paths with skeletal animation clip transitions (e.g. Walk → Idle), and timed speaker subtitle + WAV/synthesized audio cues.

11. Game Localization & Translation Editor Window (Ctrl+L)

Available under Project -> Game Localization..., Window -> Game Localization Editor, or via the Ctrl+L shortcut. This workspace empowers game developers to create, translate, and organize player-facing game text across any number of languages directly inside the engine:

Folder Storage: Game translations are stored in assets/localization/<code>.json inside the project root. When exporting a standalone game build, Tessera automatically bundles the entire assets/ directory so your game ships with all translations embedded.

Key Capabilities

  • Language Selector & Creation: Switch active editing language via a dropdown (e.g. English, Spanish). Click [+ New Language] to add a new language (e.g. fr - Français, de - Deutsch, ja - 日本語) which automatically creates the corresponding .json file with all project keys.
  • Key-Value Translation Grid: Define translation keys (e.g. menu_play, quest_hero_intro) along with default English reference text. Each key displays its current translation in an editable text box.
  • Real-Time Search & Status Badges: Filter translation keys or translated text instantly. Color-coded badges indicate whether a key is Translated (green) or Untranslated (orange).
  • Zero-Code UI Binding: Any 2D UI Node (such as UITextNode or UIButtonNode) can be assigned a Localization Key in the Inspector. The node automatically displays the translated text in whatever language the player selects in-game!
  • In-Game Lua Integration: Scripts can call TR("key") or Localization.Translate("key"), and query Localization.GetAvailableLanguages() to populate in-game language option menus. Changing language via Localization.SetLanguage(code) dynamically refreshes all UI text on the next frame.
