2D UI Component Nodes

The Tessera Engine includes a complete, high-performance 2D screen-space and world-space UI widget system. All 25+ UI nodes inherit from UINode (src/Scene/Nodes/UI/UINode.h) and are rendered using optimized screen-aligned vertex quads with anchor-based responsive layout scaling.

2. Anchor and Responsive Layout System

Every UINode features an anchor model that ensures UI screens scale correctly from 720p up to 4K ultrawide displays:

  • Anchors (0.0 to 1.0): Pin the UI element relative to the parent's corners (e.g., Top-Left, Center, Bottom-Right, Full Stretch).
  • Offsets (Pixels): Pixel distance from anchor points for fixed margins and paddings.
  • Pivot Point (0.0 to 1.0): Center of rotation and scaling for the widget ((0.5, 0.5) centers the widget).

3. UI Text Localization System

All text-bearing UI nodes (including UITextNode, UIButtonNode, UICheckboxNode, etc.) support direct binding to the engine's translation dictionary:

  • Localization Key: Enter a key (e.g. menu_play, settings_audio) in the Node Inspector's Localization Key (Optional) field.
  • Dynamic Resolution: Instead of hardcoded text, the widget dynamically queries GameLocalization for the active game language.
  • Live In-Game Switching: When the player switches languages via Localization.SetLanguage(code) or an in-game menu, all bound UI elements update immediately on the next frame without reloading scenes or restarting the game.
  • Automatic Fallback: If a string is not yet translated in the active language, it seamlessly falls back to English, preventing blank UI labels.

4. Auto-Layout Containers: Box & Grid Containers

Tessera includes smart auto-layout containers that eliminate the need for manual pixel placement when designing adaptive interfaces:

UIBoxContainerNode (NodeType::UI_BoxContainer)

Arranges child elements sequentially in a single direction:

  • Orientation: BoxOrientation::Horizontal or BoxOrientation::Vertical.
  • Spacing: Configurable pixel distance between adjacent elements.
  • Padding: Border inset spacing from container edges.
  • AutoResize: Dynamically recalculates the container's total width and height based on child bounds.

UIGridContainerNode (NodeType::UI_GridContainer)

Arranges child elements in a multi-column, multi-row matrix:

  • Columns: Number of columns per row (e.g. 4 for an inventory hotbar).
  • Cell Dimensions: Uniform cellWidth and cellHeight for each grid slot.
  • Horizontal & Vertical Spacing: Independent gutter gaps between columns and rows.
  • Padding: Outer margins protecting grid contents.

5. Video & Media UI Components

The UIVideoNode (src/Scene/Nodes/UI/UIVideoNode.h) provides dedicated 2D screen-space video playback inside in-game user interfaces, menus, smartphone HUDs, security room terminal feeds, and computer terminal monitors.

UIVideoNode Capabilities

  • Dual Playback Engine: Backed by VideoSystem, supporting external GIF files, sprite-sheet video atlases, numbered PNG frame folders, and procedural broadcasts (TV News, CCTV, CRT, Sci-Fi Radar).
  • Interactive Click-to-Play: Clicking the video widget in-game toggles playback (play/pause) or switches channels automatically.
  • Form-Factor Aspect Ratios: Presets for 16:9 widescreen TV, 2.39:1 cinema ultrawide, 9:16 mobile smartphone portrait, and 4:3 CRT/CCTV displays.
  • Post-Processing Scanlines: Optional horizontal phosphor scanline filter with adjustable intensity (scanlineStrength).
  • Audio Integration: Synchronized audio playback with per-widget volume controls.

3. Step-by-Step: Creating an In-Game HUD & Health Bar

  1. Create Canvas: Press Ctrl+A → 2D UI: Containers & Layout → Canvas (UI Root).
  2. Add Player Health Bar: Right-click the Canvas → Add 2D UI → Basic & Text → Progress Bar.
    • Set Position to (20, 20).
    • Set Size to (240, 28).
    • Set Fill Color to bright red (0.9, 0.2, 0.2, 1.0).
    • Set Background Color to dark charcoal (0.15, 0.15, 0.15, 1.0).
  3. Add Health Label: Right-click the Progress Bar → Add 2D UI → Text Label.
    • Set Text to "HP: 100 / 100".
    • Set Alignment to Center.
  4. Scripting the Health Bar in Lua: Attach a Lua script to the Canvas: 
    function OnUpdate(self, dt)

    local player = Scene.find_node_by_name("PlayerHero")

    if player then

        local healthBar = Scene.find_node_by_name("HealthBar")

        if healthBar then

            healthBar:set_ui_progress(player:get_health_ratio())

        end

    end

end
