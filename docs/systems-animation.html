Animation, Armatures, IK, State Machines & Cutscenes

Tessera features a full-featured skeletal and cinematic animation suite (src/Animation/) supporting rigged characters (FBX, glTF 2.0), bone hierarchy transforms, Inverse Kinematics (IK), Blend Shapes / Morph Targets, a Visual Animation State Machine graph, and an In-Engine Cutscene & Cinematic Sequencer.

1. Skeletal Skinning Pipeline

When an FBX or glTF model containing an armature is loaded, the engine imports:

  • Bone Joint Hierarchy: Parent-child bone trees with relative joint translation, rotation (quaternion), and scale.
  • Inverse Bind Matrices: Precomputed inverse world matrices for each bone in reference bind pose.
  • Vertex Skinning Attributes: Up to 4 bone IDs and 4 normalized floating-point weights per vertex.
  • GPU Skinning: Linear blend skinning runs in a compute shader (shaders/skinning.comp, VulkanSkinning) into a buffer per character, shared by every render pass. Last frame's pose is kept so TAA and motion blur follow moving limbs without smearing.

Per-Character Animation Clock

Every animated node keeps its own clock, so a crowd of identical characters does not move in lockstep. In the Inspector's Armature & Animation Tree section:

  • Play Animation: plays or pauses this character (off holds the rest pose). In the editor this previews just this node.
  • Animation Speed: playback rate for this character, multiplied with the clip's own speed.
  • Start Offset (s): seconds into the clip this character starts at.

2. Inverse Kinematics (IK) Solvers

Configurable directly in the Node Inspector under Inverse Kinematics (IK) & Morph Targets:

Two-Bone Analytical IK Solver

Solves standard two-link humanoid limb chains (e.g. Hip → Knee → Ankle or Shoulder → Elbow → Wrist):

  • End-Effector Bone: The target joint name (e.g. "Ankle_R").
  • Target World Position: World coordinate the foot or hand should reach.
  • Pole Vector: Guide vector indicating the bend direction of the knee or elbow (prevents unnatural joint flips).
  • IK Blend Weight: 0.0 (pure keyframed animation) to 1.0 (pure IK goal).

FABRIK Multi-Joint Solver

Forward And Backward Reaching Inverse Kinematics (FABRIK) solves arbitrary multi-bone kinematic chains (e.g., spines, tails, insect legs, mechanical cranes) via iterative forward and backward passes.

3. Blend Shapes & Morph Targets

Supports live facial animation and soft-body deformation. Each morph target stores per-vertex displacement vectors (Δx, Δy, Δz). The engine interpolates multiple active shapes simultaneously (e.g., Smile = 0.8, Blink_L = 1.0, Jaw_Open = 0.4) in real time.

4. Animation Timeline & Scrubbing Window

Located across the bottom of the editor workspace:

  • Transport Controls: Play, Pause, Stop, Loop Toggle.
  • Timeline Scrubber: Drag to inspect any precise frame in the animation.
  • Animation Clip Selector: Dropdown showing all clips embedded in the model (e.g., Idle, Run, Jump, Slash_Combo).
  • Playback Speed: Adjustable playback rate (0.25x slow motion to 2.0x fast forward).

5. Visual Animation State Machine Graph

Accessible via Shift+M or Window → Animation State Machine Graph:

  • State Nodes: Each box represents an animation clip state (e.g. Idle, Walk, Attack).
  • Directed Transitions: Drag from one state node to another to create a transition.
  • Crossfade Blend Duration: Set smooth blend times (e.g., 0.2s crossfading from Walk into Jump).
  • Controlling from Lua: 
    function OnUpdate(self, dt)

    if Input.is_key_pressed("W") then

        self:set_animation_state("Walk")

    else

        self:set_animation_state("Idle")

    end

end

6. In-Engine Cutscene & Cinematic Sequencer

Accessible via Shift+C, Window → Cutscene & Cinematic Sequencer, or Scene → Cutscene & Cinematic Sequencer... (src/Animation/Cutscene.h / Cutscene.cpp):

  • Real-Time In-Engine Cinematics: Choreographs existing scene characters and cameras directly in the active 3D world without pre-rendered video files.
  • Location Proximity Triggering: Automatically triggers when any character (*) or a named actor walks within a configurable 3D world coordinate and radius.
  • Multi-Shot Camera Cuts, Dollies & Live Actor Tracking: Smooth Hermite or linear camera movement, FOV zoom ramps, and live Look-At actor tracking with automatic Depth-of-Field (DoF) focus distance locking.
  • Character Walk-to-Mark & Animation State Transitions: Moves actors from their current position (or a custom start mark) to a destination mark while driving their skeletal AnimationTree states (e.g. "Walk" during movement → "Idle" or "Wave" on arrival).
  • Cinematic Camera & Color Grading Effects: Per-cutscene post-processing overrides including Sepia Tone, Black & White (Monochrome), High-Contrast Noir (B&W), Vintage 35mm Warm, Cold Moonlight, Dreamy Flashback Bloom, Vignette, 35mm Film Grain, Chromatic Aberration, and 2.39:1 Widescreen Letterbox bars.
  • Audio or Silent Mode + Subtitles: Timed speaker and dialogue subtitle banners in the bottom letterbox bar with optional .wav or synthesized audio cues, or 1-click Silent Mode.
  • Skippable Playback (Space / Enter / Backspace or UI Button): Safely fast-forwards all cutscene actors to their final destination marks and end animation states, stops cutscene audio, and restores the pre-cutscene camera and SceneEnvironment.

7. Motion Matching & Procedural Full-Body IK (AAA Standard)

To eliminate rigid state transition trees and manual blend spaces, Tessera implements a data-driven Motion Matching engine (Animation::MotionMatcher) coupled with Procedural Full-Body IK (Animation::FullBodyIKSolver):

Continuous Trajectory & Pose Search

Instead of manually keyframing transition logic, the motion matcher continuously searches a motion database of captured animations every frame to find the frame that simultaneously minimizes:

  • Desired Trajectory Matching: Compares user stick trajectory predictions at future points (+0.2s, +0.4s, +0.6s) with the animation's actual path.
  • Pose Feature Matching: Matches foot positions, foot velocities, and root momentum to ensure continuous gait continuity.
  • Inertialization Blending: A 5th-order quintic polynomial decay filter eliminates foot-popping and transition artifacts when switching to distant clips.

Procedural Full-Body IK (FBIK)

Ensures realistic character interaction with uneven 3D terrain:

  • Pelvis Height Adaptation: Dynamically lowers the pelvis root bone based on the lowest ground contact point of either foot.
  • Two-Foot Terrain Normal Conform: Rotates and bends ankle joints to conform flush to uneven ground slopes via TwoBoneIK.
  • Spine & Head Look-At: Smoothly rotates upper spine and head bones toward look targets, camera focus, or combat adversaries.
