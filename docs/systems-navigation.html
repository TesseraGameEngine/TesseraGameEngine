Navigation, NavMesh & AI Patrol

The Tessera AI Navigation subsystem (src/Navigation/) provides automated Navigation Mesh (NavMesh) voxelization, convex polygon decomposition, multi-agent A* pathfinding, and high-level humanoid NPC patrol behaviors.

1. The NavMesh Baker

Accessible via Shift+N or Window → Navigation & NavMesh Baker:

  • Voxel Rasterization: Voxelizes all static scene colliders into a solid heightfield.
  • Walkable Surface Filtering: Filters out steep triangles exceeding Max Slope Angle (default 45°).
  • Agent Dimensions:
    • Agent Radius: Erodes walkable edges by the agent's radius (e.g. 0.5m) to prevent characters from clipping into walls.
    • Agent Height: Clears underpasses, tunnels, and ceilings lower than the character's clearance height (e.g. 2.0m).
    • Max Step Height: Allows agents to step over curbs and stair risers (e.g. 0.35m).
  • Convex Polygon Partitioning: Simplifies the heightfield into a 2D polygonal navigation mesh graph.

2. A* Pathfinding Engine

When an agent requests a path between Point A and Point B:

  1. Polygon Search: The A* algorithm finds the optimal polygon corridor connecting the start and goal nodes using Euclidean distance heuristics.
  2. Funnel Algorithm (String Pulling): Optimizes the route through polygon portals, producing straight-line, natural waypoints rather than zigzagging through triangle centers.

3. Humanoid NPC Patrol & Steering

The CharacterNode class incorporates an autonomous patrol controller:

💡 Setting Up an NPC Patrol in Seconds
  1. Add a Character NPC node to your scene.
  2. Move the character to the patrol start position and click Add Current Position as Waypoint.
  3. Move the character to location 2, click Add Current Position as Waypoint.
  4. Repeat for locations 3 and 4, then check Is Patrolling and Loop Waypoints.
  5. Press F5 — the NPC immediately turns and patrols smoothly between your waypoints!

Patrol Steering Mechanics

  • Smooth Yaw Rotation: Steers smoothly towards target waypoints using angular interpolation with turnSpeed.
  • Arrival Tolerance: Detects waypoint arrival when planarDistance <= waypointTolerance (default 0.5m).
  • Ground Raycast Clamping: Keeps the NPC's feet locked to stairs, slopes, and terrain via downward physics raycasts.
  • Animation Sync: Automatically plays walkAnimClip during movement and returns to idleAnimClip when reaching terminal stops.
