Physics Engine, RigidBodies & Ragdolls

The Tessera Engine integrates JoltPhysics (src/Physics/), the AAA multi-threaded physics engine powering modern open-world titles, providing high-precision collision detection, dynamic constraint solvers, continuous collision detection (CCD), and realistic humanoid ragdoll simulation.

1. RigidBody Modes

Configurable for any 3D node under the Physics & Dynamics Inspector header:

ModeSimulation TypeCollision BehaviorIdeal Use Cases

2. Physical Material Properties

  • Mass (kg): Weight of the body (affects momentum and collision impulse response).
  • Floats on Water (Dynamic bodies): in an Ocean, the body bobs and tilts with the waves, using Jolt's buoyancy against the wave surface under it. Buoyancy: 1 = neutral, below 1 sinks, above 1 rides higher.
  • Use Gravity: When checked, the body accelerates downward using the world gravity vector (default -9.81 m/s²).
  • Friction (0.0 to 1.0): Coulomb surface friction opposing sliding motion.
  • Restitution / Bounciness (0.0 to 1.0): Coefficient of restitution (0.0 = completely inelastic, 1.0 = perfect elastic bounce).
  • Linear Velocity (vec3): Current directional movement velocity vector.
  • Angular Velocity (vec3): Current rotational angular spin vector.

3. Constraints & Joint Solvers

Joints connect two physics bodies together with restricted degrees of freedom:

  • Fixed Joint: Rigidly locks position and orientation between two bodies.
  • Hinge Joint: Constrains rotation around a single axis with optional angular limits (swinging doors, wheel axles).
  • Slider Joint: Constrains movement to a single translational axis (hydraulic pistons, sliding drawers).
  • Distance Spring: Damped harmonic spring maintaining a target distance between two attachment points.
  • Cone-Twist Joint: Ball-and-socket joint with cone and twist angle limits used for ragdoll shoulders, hips, and necks.

4. Humanoid Ragdoll Physics

Check Enable Humanoid Ragdoll Physics on any character node with an armature:

  • The engine binds capsule colliders to each bone joint connected by Cone-Twist and Hinge constraints.
  • Click Apply Upward Ragdoll Impulse Test in the Inspector to immediately see the character knocked backward with physical momentum.
  • Smoothly blending from animated keyframes into dynamic ragdolls on character defeat or heavy projectile impacts.

5. 32-Bit Collision Filtering (Layers & Masks)

Tessera provides fine-grained 32-bit collision filtering directly integrated into Jolt Physics narrowphase via TesseraContactListener (inheriting JPH::ContactListener::OnContactValidate):

  • Collision Layer (32-bit bitfield): Defines which category/categories this entity belongs to (e.g., Layer 1 = World/Environment, Layer 2 = Player, Layer 3 = Enemies, Layer 4 = Projectiles).
  • Collision Mask (32-bit bitfield): Defines which layers this entity is allowed to scan and collide against.
ℹ Symmetric Collision Rule

Two entities $A$ and $B$ only generate contact manifolds if both agree to collide:

CanCollide = ((layerA & maskB) != 0) && ((layerB & maskA) != 0)

If this condition evaluates to false, Jolt Physics immediately rejects the contact pair before solver impulses or constraint iterations run, yielding substantial performance gains in scenes with high entity counts.

Configuring Collision Bitfields in Lua

function OnInit(self)
    -- Set Player to Layer 2 (bit 1) and scan Layers 1 (World) & 3 (Enemies)
    self:SetCollisionLayer(2)
    self:SetCollisionMask(1 | 4) -- 5

    -- Query whether we can collide with another node
    local enemyId = 42
    if self:CanCollideWith(enemyId) then
        print("Player can collide with enemy!")
    end
end

6. GPU Cloth Simulation (XPBD) & Dynamic Hair Physics (AAA Standard)

Tessera includes secondary character physics simulation via Extended Position-Based Dynamics (Physics::XPBDClothSimulator and Physics::DynamicHairSimulator):

XPBD Cloth Simulation

  • Time-Step Independent Compliance: Physical compliance parameter α ensures stiffness does not fluctuate with framerate changes or substepping.
  • Multi-Constraint Particle Mesh: Solves structural springs, diagonal shear constraints, and isometric bending constraints across quad cloth meshes.
  • Aerodynamic Drag & Wind Forces: Dynamic surface velocity drag coupled with global wind velocity vectors from Weather.
  • Kinematic Capsule Collisions: Continuous collision avoidance against character limbs, head, and torso capsules to prevent fabric penetration.

Dynamic Hair Rod Physics

  • Elastic Rod Strands: Multi-segment hair strands with root pinning to the scalp, segment length constraints, and bending stiffness.
  • Inertia & Gravity: Dynamic motion responding naturally to character movement, head turns, jumps, and wind forces.
