Lua Scripting API Reference

The Tessera Engine embeds a full Lua 5.4 runtime (src/Scripting/) allowing gameplay mechanics, character controllers, user interfaces, and multiplayer network replication to be scripted with zero recompile times and live hot-reloading.

1. Node Script Lifecycle Callbacks

When a Lua script is bound to a node (via the Script File slot in the Inspector), the engine invokes the following lifecycle events:

CallbackSignatureTiming & Description
OnInit(self)function OnInit(self)Called once when the game enters Play Mode (F5) or when the node is spawned dynamically at runtime. Ideal for initializing variables, caching references, and playing entrance animations.
OnUpdate(self, dt)function OnUpdate(self, dt)Called every frame during Play Mode. Receives dt (delta time in floating-point seconds, e.g. 0.0166 for 60 FPS). Use for movement, input handling, and game logic.
OnDestroy(self)function OnDestroy(self)Called immediately before the node is removed from the scene or when Play Mode stops. Ideal for cleanup, spawning death particles, or dropping loot.
OnCollision(self, other_id)function OnCollision(self, other_id)Invoked by JoltPhysics when this node's collider intersects with another solid collider. Receives the numerical id of the other node.

Input Module (Input)

  • Input.is_key_pressed(key) — Returns true while key is held down (e.g. "W", "A", "Space", "Shift").
  • Input.is_action_pressed(action) — Returns true while action mapping is held down (e.g. "MoveForward", "Jump", "Fire").
  • Input.get_axis(axis) — Returns analog axis value (-1.0 to +1.0) from keyboard or gamepad joystick.
  • Input.get_mouse_position() — Returns screen-space mouse cursor X and Y coordinates.

Physics Module (Physics)

  • Physics.apply_force(node_id, fx, fy, fz) — Applies continuous force in Newtons over the physics step.
  • Physics.apply_impulse(node_id, ix, iy, iz) — Applies an instantaneous momentum impulse (N·s).
  • Physics.set_linear_velocity(node_id, vx, vy, vz) — Overwrites linear velocity directly.

Signal Module (Signal)

  • Signal.Emit(node_id, signal_name, ...args) — Global helper to emit a signal on any target node by ID.

Resource Module (Resource)

  • Resource.GetLoadedCount() — Returns the total count of deduplicated assets currently cached in memory.
  • Resource.GetMemoryUsage() — Returns the approximate memory consumption of all loaded resources in bytes.
  • Resource.UnloadUnused() — Purges all cached resources whose only remaining reference is the cache, returning the count of unloaded assets.

Sky Module (Sky)

  • Sky.SetTime(hours) — Sets the time of day (0..24) and turns the clock on.
  • Sky.GetTime() — Returns the time of day in hours.
  • Sky.SetDayLength(minutes) — Real minutes for a whole day; 0 stops the clock.
  • Sky.SetMoonPhase(phase) — 0 new, 0.25 first quarter, 0.5 full, 0.75 last quarter.
  • Sky.SetDate(day) — The day of the year (1..365): the season, so how high the sun climbs and how long the days are.
  • Sky.GetDate() — Returns the day of the year.
  • Sky.SetClouds(coverage [, opacity]) — Turns clouds on; coverage 0 clear to 1 overcast.
  • Sky.SetWind(speed [, direction]) — Wind speed (m/s) and the direction it blows toward (degrees), moving the clouds.

Terrain Module (Terrain)

  • Terrain.GetHeight(x, z) — The ground's height at a world position (nil off every terrain).
  • Terrain.GetLayer(x, z) — The paint layer most present there (1..4) and its name, e.g. to pick footstep sounds.

Weather Module (Weather)

  • Weather.Set(name [, seconds]) — Blends to a preset: "Clear", "Cloudy", "Overcast", "Rain", "Storm" or "Snow", over the given seconds.
  • Weather.Get() — The current preset's name, or "Custom" with presets off.
  • Weather.SetRain(amount), Weather.SetSnow(amount), Weather.SetWetness(amount), Weather.SetSnowCover(amount) — Set directly (0..1); these turn presets off.
  • Weather.SetLightning(perMinute) — How often lightning strikes (turns presets off).
  • Weather.SetSnowDepth(metres) — How deep the snow lies at full cover.
  • Weather.SetThunderVolume(volume) — 0 silences thunder, 1 is full volume.
  • Weather.Strike() — A lightning strike now.
  • Weather.GetStrikeCount() — Goes up by one with each strike (the engine plays thunder itself; use this for anything else).

Scene Prefabs & Instancing (Scene)

  • Scene.Instantiate(scene_path, [parent_id], [x, y, z]) — Spawns an external .tess subscene into the hierarchy as a live linked prefab instance.
  • Scene.ReloadInstance(instance_node_id) — Dynamically repopulates an instanced subtree from its source file.

Audio Module (Audio)

  • Audio.play_sound(asset_name, volume) — Fires a 2D sound effect across the SFX bus.

Cutscene & Cinematic Module (Cutscene)

  • Cutscene.Play(name) — Starts the named CutsceneSequence in the active scene; returns true if found and started.
  • Cutscene.Skip() — Skips the active cutscene if skippable, fast-forwarding actors to their final destination marks and end animation states and restoring the scene camera & environment.
  • Cutscene.Stop() — Stops the active cutscene and restores the pre-cutscene camera and environment.
  • Cutscene.IsPlaying() — Returns true while an in-engine cutscene is actively playing.
  • Cutscene.GetTime() — Returns the current playback time (in seconds) of the active cutscene.
  • Cutscene.GetName() — Returns the string name of the currently playing cutscene (or "" if none).

Video & In-Game Screens Module (Video)

  • Video.Play(node_id) — Starts playback on the specified 3D screen node or UI video element.
  • Video.Pause(node_id) — Pauses video playback on the target node.
  • Video.Stop(node_id) — Stops playback and rewinds to timestamp 0.0s.
  • Video.SetChannel(node_id, channel_preset) — Switches the broadcast channel preset (0=Custom, 1=Cinema, 2=TV News, 3=CCTV, 4=Smartphone, 5=CRT Bars, 6=Sci-Fi Radar).
  • Video.SetSource(node_id, file_path) — Assigns an external animated GIF, sprite-sheet atlas, or sequential frame directory.
  • Video.Seek(node_id, timestamp) — Seeks playback to a specific timestamp in seconds.
  • Video.IsPlaying(node_id) — Returns true if the specified video screen is currently playing.
  • Video.PlayCutaway(title, channel, duration, is_pip) — Triggers an immediate full-screen or corner Picture-in-Picture (PiP) video cutaway transmission overlay. Skippable at any time with Space or Enter.
  • Video.StopCutaway() — Dismisses the active cutaway overlay and restores standard camera view.
  • Video.IsCutawayPlaying() — Returns true while a cutaway video transmission is actively displaying.

Network Module (Network)

  • Network.get_unique_id() — Returns local peer ID (1 for Server/Host, 2+ for Clients).
  • Network.is_server() — Returns true if the local engine is hosting the authoritative server.
  • Network.rpc(func_name, ...) — Sends a Remote Procedure Call to all peers or the authority holder.

Scene Module (Scene)

  • Scene.find_node_by_name(name) — Returns the first node matching the string name.
  • Scene.get_node(id) — Returns the node instance matching the ID.
  • Scene.add_character_node(name) — Dynamically instantiates a humanoid character node into the scene.

2.16 Localization & Internationalization Global API (Localization & TR)

Tessera provides native game localization support in Lua. Game developers can look up translated strings dynamically, change the player's active language at runtime, and query available languages to build in-game language selection menus.

FunctionParametersReturnsDescription
TR(key, [default])key: string, [default: string]stringGlobal shorthand function. Returns the translated text for key in the player's active language, falling back to English or default.
Localization.Translate(key, [default])key: string, [default: string]stringResolves a translation key using the active game language table.
Localization.Get(key)key: stringstringAlias for Localization.Translate.
Localization.SetLanguage(code)code: stringbooleanSets the active game language (e.g. "en", "es", "fr"). Automatically updates all UI nodes bound via Localization Key on the next frame.
Localization.GetLanguage()—stringReturns the current active game language code (e.g. "es").
Localization.GetAvailableLanguages()—tableReturns an array of available languages discovered in assets/localization/: { { code = "en", name = "English" }, { code = "es", name = "Español" }, ... }.
self:SetLocKey(key)key: string—Binds a translation key directly to this UI node.
self:GetLocKey()—stringReturns the bound translation key of this UI node.
Scene.SetLocKey(nodeId, key)nodeId: int, key: string—Sets the localization key on a specific UI node by ID.
Example: Building an In-Game Language Selector & Localized Dialogue in Lua
-- Attached to an In-Game Settings Menu or Dialogue Node
function OnReady()
    -- 1. Populate dropdown or menu with available languages:
    local languages = Localization.GetAvailableLanguages()
    for i, lang in ipairs(languages) do
        print("Available Language: " .. lang.code .. " (" .. lang.name .. ")")
    end

    -- 2. Display localized NPC dialogue:
    local greeting = TR("dialog_welcome", "Welcome, traveler!")
    self:SetText(greeting)
end

-- Called when the player selects a language in the options menu
function OnLanguageSelected(selectedLangCode)
    Localization.SetLanguage(selectedLangCode) -- e.g. "es"
    print("Game language changed to: " .. Localization.GetLanguage())
    -- All UI elements with a Localization Key update immediately!
end

3. Production-Ready Script Templates

Template A: Third-Person Character Controller

local moveSpeed = 6.0

local jumpForce = 450.0



function OnInit(self)

    print("Player controller initialized on: " .. self:get_name())

end



function OnUpdate(self, dt)

    -- Authority check: Only the owner controls their character!

    if not self:is_multiplayer_authority() then

        return

    end



    local dx = 0

    local dz = 0



    if Input.is_key_pressed("W") then dz = dz - 1 end

    if Input.is_key_pressed("S") then dz = dz + 1 end

    if Input.is_key_pressed("A") then dx = dx - 1 end

    if Input.is_key_pressed("D") then dx = dx + 1 end



    if dx ~= 0 or dz ~= 0 then

        -- Normalize vector

        local len = math.sqrt(dx * dx + dz * dz)

        dx = (dx / len) * moveSpeed * dt

        dz = (dz / len) * moveSpeed * dt

        self:translate(dx, 0, dz)

        self:set_animation_state("Walk")

    else

        self:set_animation_state("Idle")

    end



    if Input.is_action_pressed("Jump") then

        Physics.apply_impulse(self:get_id(), 0, jumpForce, 0)

        self:set_animation_state("Jump")

    end

end

Template B: Proximity Dialogue & Interaction Trigger

local interactDist = 3.5



function OnUpdate(self, dt)

    local player = Scene.find_node_by_name("PlayerHero")

    if not player then return end



    local px, py, pz = player:get_position()

    local mx, my, mz = self:get_position()

    local dist = math.sqrt((px - mx)^2 + (py - my)^2 + (pz - mz)^2)



    local hudText = Scene.find_node_by_name("InteractionPrompt")

    if hudText then

        if dist <= interactDist then

            hudText:set_visible(true)

            if Input.is_key_pressed("E") then

                print("Interacting with: " .. self:get_name())

                Audio.play_sound("quest_accept.wav", 1.0)

            end

        else

            hudText:set_visible(false)

        end

    end

end

4. C++ sol2 Binding API

The engine includes full support for sol2 (src/sol/sol.hpp), allowing modern C++20 type-safe Lua bindings without manual Lua C-API stack management.

  • Access Engine Lua State with sol2: 
    #include "Scripting/LuaScriptSystem.h"

#include <sol/sol.hpp>



// Get sol2 wrapper over engine runtime

sol::state_view lua = Scripting::LuaScriptSystem::Get().GetSolState();



// Bind custom C++ classes / usertypes

struct QuestManager {

    std::string activeQuest;

    int progress{0};

    void Advance() { progress++; }

};



lua.new_usertype<QuestManager>("QuestManager",

    "quest", &QuestManager::activeQuest,

    "progress", &QuestManager::progress,

    "advance", &QuestManager::Advance

);



// Call Lua functions with type safety

sol::function onPlayerDeath = lua["OnPlayerDeath"];

if (onPlayerDeath.valid()) {

    onPlayerDeath(101, "FallDamage");

}

5. Reactive Signals & Observer Pattern

Tessera includes a first-class decoupled event and signal system in Lua. Entities can broadcast events without needing direct references to listening widgets or subsystems:

function OnInit(self)
    -- Subscribe to an event on another node (e.g. Player)
    local player = Scene.find_node_by_name("PlayerHero")
    if player then
        self.connId = player:Connect("on_damage_taken", function(amount, source)
            print("Hero damaged: " .. tostring(amount) .. " by " .. tostring(source))
            -- Update local health bar
            self:SetProgressBarValue(self:GetProgressBarValue() - amount)
        end)
    end
end

function take_damage(amount)
    -- Emit a signal to all connected listeners
    self:Emit("on_damage_taken", amount, "SpikeTrap")
end

function OnDestroy(self)
    -- Optional: Explicitly disconnect signal listener
    local player = Scene.find_node_by_name("PlayerHero")
    if player and self.connId then
        player:Disconnect("on_damage_taken", self.connId)
    end
end

6. Nested Scene Instancing & Prefabs

Any .scene file in the project's scenes/ or prefabs/ directory can be dynamically instanced at runtime via Lua:

function spawn_loot_chest(x, y, z)
    -- Instantiate reusable Chest.scene prefab with position offset
    local chest = Scene.Instantiate("prefabs/Chest.scene", 0, x, y, z)
    if chest then
        print("Spawned chest with root ID: " .. tostring(chest:get_id()))
    end
end

function reload_prefab_on_upgrade()
    -- Hot-reload the instanced sub-tree directly from disk
    local success = self:ReloadInstance()
    print("Prefab reloaded: " .. tostring(success))
end

7. Shared Resource Handles & Asset Deduplication

Shared heavy assets (3D meshes, textures, materials, and audio clips) are tracked by the engine's ResourceManager. Lua can query runtime asset metrics and trigger garbage collection:

function check_memory_footprint()
    local activeAssets = Resource.GetLoadedCount()
    local memoryBytes = Resource.GetMemoryUsage()
    print("Active GPU Assets: " .. tostring(activeAssets))
    print("VRAM / RAM Allocated: " .. string.format("%.2f MB", memoryBytes / (1024 * 1024)))

    -- Garbage-collect unused asset buffers whose reference counts have reached zero
    local purged = Resource.UnloadUnused()
    print("Purged unreferenced assets: " .. tostring(purged))
end
